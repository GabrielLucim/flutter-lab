# Flutter Lab — Meu Painel de Missões

Página web interativa para o Trabalho 2 do 3º trimestre. Ela ensina fundamentos de Dart e a passagem para uma tela Flutter usando o contexto de um pequeno aplicativo de metas de estudo, pensado para adolescentes que ainda não programam.

## Como abrir

Não há instalação nem dependências.

1. Mantenha **index.html**, **style.css** e **script.js** na mesma pasta.
2. Abra **index.html** em um navegador moderno.

Se preferir servir a pasta localmente, abra um terminal nesta pasta e use:

    python -m http.server 8000

Depois, visite http://localhost:8000.

## O que demonstrar na apresentação

1. Mostre o contexto: o aluno constrói o **Meu Painel de Missões**, não apenas resolve exercícios soltos.
2. Faça a primeira missão e deixe uma resposta errada de propósito para destacar o feedback específico e as três dicas progressivas.
3. Pule para “O app precisa escolher” e explique por que >= é diferente de >.
4. Mostre a árvore de widgets, a montagem de Scaffold e a escolha entre Column e Row.
5. Termine na missão de estado: clique no botão da prévia e diga com clareza que ele é uma simulação em JavaScript; no Flutter real, a ideia equivalente é setState.

## Limite assumido com honestidade

Este protótipo não instala, compila ou executa Dart/Flutter. Ele confere a estrutura de respostas e mostra prévias ilustrativas para ensinar a lógica. O progresso, rascunhos e dicas ficam salvos apenas no navegador atual, via armazenamento local.

Para uma continuação, o código da tela poderia ser levado para um projeto Flutter real ou experimentado no DartPad.
